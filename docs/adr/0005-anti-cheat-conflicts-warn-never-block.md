# Anti-cheat conflicts warn and never block

When a tweak or driver conflicts with an anti-cheat (Memory Integrity off breaks Vanguard and can block FACEIT, and
FACEIT blocks PawnIO), the app names the installed games it affects and still lets the user go ahead. The research
found these conflicts stop a game launching or limit it, rather than cost the account, and the PC is the user's to
decide about. The exception is the never-touch rule: test signing, driver-signature and kernel-debugging changes and
known-vulnerable drivers are refused in every mode, Advanced included.
