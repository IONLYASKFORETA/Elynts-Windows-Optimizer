# No presets

The app has no one-click presets: every tweak has its own switch and description, and nothing applies a group of
tweaks the user hasn't looked at one by one. Presets are the usual design in tools like WinUtil, so this is
deliberate (Aden, 2026-10-15): it keeps every change one the user chose after reading what it does and how good the
evidence is. Per-game profiles and app lists don't count as presets, because the user builds them and the app ships
none.
