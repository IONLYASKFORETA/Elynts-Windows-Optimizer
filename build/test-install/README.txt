Elynt's Windows Optimizer - test build

1. Before unzipping: right-click the zip, choose Properties, tick "Unblock", then OK.
2. Unzip it anywhere.
3. Right-click install.cmd and choose "Run as administrator".
4. Open app\ElyntOptimizer.exe normally (not as administrator).
   If Windows says "Windows protected your PC", click "More info" then "Run anyway".
5. To remove it: turn your tweaks off in the app, then run uninstall.cmd as administrator.

Logs: %ProgramData%\ElyntOptimizer\logs (service) and %LocalAppData%\ElyntOptimizer\logs (app).
